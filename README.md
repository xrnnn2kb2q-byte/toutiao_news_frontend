# Toutiao News Frontend

基于 Vue 开发的新闻头条前端项目，用于展示新闻分类、新闻列表及新闻详情页面，并通过 Axios 与 FastAPI 后端进行数据交互。

## 项目介绍

本项目是新闻头条系统的前端部分，采用 Vue 框架实现页面开发，通过调用 FastAPI 后端接口完成新闻数据展示。项目主要用于学习 Vue 开发、组件化设计以及前后端分离开发模式。

## 技术栈

- Vue
- JavaScript
- HTML5
- CSS3
- Axios

## 功能模块

- 首页展示
- 新闻分类导航
- 新闻列表展示
- 新闻详情页面
- 前后端数据交互
- 响应式页面布局
